# Círculo de Quintas

Círculo de quintas con piezas intercambiables. Cada pieza es una máscara que deja ver solo las notas y los acordes de una escala.

- **Rotar la pieza** cambia la tónica (transporta).
- **Cambiar la pieza** cambia la forma de la escala: Mayor (y sus 7 modos), Menor armónica y Pentatónica.
- **Transportar por grados**: escribe una progresión como `I V vi IV` y la ves en cualquier tonalidad.

Abre `index.html` en el navegador o visita la versión publicada en GitHub Pages.
